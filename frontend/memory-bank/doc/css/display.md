# Display

`.d-none`, `.d-block`, `.d-flex`

**Flex helpers** (no .d-flex needed): `.f-column`, `.f-column-reverse`, `.f-center`, `.f-equal` (flex:1 on children)
**Responsive** `-md` suffix (>768px): `.f-column-md`, `.f-column-reverse-md`

**Justify** `.j-{pos}`: center, between, around, start, end. Responsive: `.j-{pos}-md`
**Align** `.a-{pos}`: center, between, around, start, end. Responsive: `.a-{pos}-md`

**Child classes:** `.f-wrap`, `.flex-1`
