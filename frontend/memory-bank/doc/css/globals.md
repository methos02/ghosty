# Global CSS

**Margin/Padding** `{m|p}{dir}-{5-50}`: dirs = (all), x, y, t, r, b, l. Multiples of 5.
**Gap** `.g-{5-50}`
**Font size** `.fs-{300|400|600|700|2rem|3rem|4rem|5rem}`, `.fs-icon-{300|400}`, `.fw-700`
**Text** `.text-center`, `.text-justify`, `.text-end`
**Truncate** `.truncate-line` (needs width on parent)
**Image** `.image-responsive` + `.round`
**Stripes** `.children-stripe` — gray bg on every other child
**Position** `.p-relative`
**Size** `.h-100`, `.w-100`, `.w-50`, `.w-25`, `.h-input`, `.h-header`
**Radius** `.radius-{5|10|15}`
**Other** `.hide` (opacity:0), `.b-shadow`
