# Tables

`.t-primary` — primary color header, white text
`.t-space` — padding on td/th
`.t-colored` — gray bg on alternating rows
`.t-responsive` — responsive table (add `data-label` on each td)
`.t-default` — combines t-colored + t-primary + t-space + t-responsive + sticky header (activé si le parent a `max-height` + `overflow-y: auto`)
